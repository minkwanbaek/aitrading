# NH 장중 회차 — 위험 점검 → 수집 → 필요 시 판단 → 실행 → 체결 확인

평일 09~15시 매 정각, 이 파일이 있는 aitrading 폴더에서 수행한다.
Windows는 기존 .venv/Scripts/python.exe, Linux는 .venv/bin/python을 사용한다.
코드·패키지·스크래퍼를 만들거나 수정하지 않는다. 사용자에게 터미널이나 키 입력을 시키지 않는다.
키·토큰·계좌번호·운용 원장 전체를 출력하지 않는다. .env·전략·원장을 직접 고치지 않는다.

1. INVESTMENT_POLICY.md 고정 제한과 broker.MOCK 값만 확인한다. False이면 모의 전용 예약을 종료한다.
   총 100만 원·국내만·5개 상한·종목당 20만 원·현금 25만 원·손절 -4%·손실 10만 원 중단·21일 재평가를 지킨다.
2. trade.py --scan을 먼저 실행한다. 보유 종목 손절과 계좌·미체결을 확인하며 모의 주문이 나갈 수 있다.
   AI 판단 실패나 이후 수집 실패가 있어도 이 위험 점검은 먼저 수행한다.
   확인된 당일 미체결은 접수 후 1시간 이상이면 기존 코드가 잔량 취소를 한 번 요청한다.
   취소 확정 조회 전에는 예산을 풀거나 재주문하지 않는다. 접수 불명·취소 응답 유실은 자동 재전송하지 않는다.
   실전/이전 거래일 주문은 자동 취소하지 않는다. 손절 주문 전송을 체결 완료로 보고하지 않는다.
   국내장이 닫혔으면 아래 수집·AI·결정서 실행은 생략하고 7단계로 간다.
3. collection-task.md의 장중 수집 단계만 수행한다. 새 기업 발굴·사업/재무 검증·후보 교체는 하지 않는다.
   수집에 실패하면 이번 회차의 판단·결정서 주문을 보류하고 7단계로 간다. 손절 점검은 이미 수행했다.
4. cycle.py --gate를 실행한다. 이 검사는 완료본을 읽고 Python 규칙으로 AI 호출 필요성을 정한다.
   request이면 research-task.md에 따라 같은 완료본으로 새 독립 세 세션의 투표·집계를 수행한다.
   skip이면 투표를 만들지 않는다. 생략을 새 hold 의견으로 표시하지 않는다. blocked이면 주문을 보류한다.
   새 뉴스/사업/재무, 마지막 실제 판단 가격 대비 누적 2% 변화, 기술 조건 교차, 보유/체결/취소 상태 변화,
   미실행 후보, 21일 재평가 또는 기존 결정서 만료가 요청 사유다. 보유·검증 완료 기업이 없으면 AI 호출을 생략한다.
5. cycle.py --execute를 실행한다. 이 기능이 이번 자료·점검·투표의 일치를 확인한 뒤 기존 trade.py로 전달한다.
   실제 읽는 결정서는 .cache/decision-plan.json이다. 단계 연결의 검사를 우회하지 않는다.
   새 판단이 필요했는데 실패/누락이면 이전 결정서로 대신 주문하지 않는다. 생략 회차는 검증된 기존 결정서만
   자체 유효기간 안에서 사용할 수 있다. 고정 제한·최신 시세·매수 상한·미체결·중복 주문은 다시 확인한다.
   trade.py --do를 직접 호출해 이 연결을 우회하지 않는다. broker 주문 함수·원장·결정서를 직접 고치지 않는다.
6. 재평가 연장은 최신 사업·재무 근거와 세 판단자의 집계로만 처리한다. 미검증이면 연장 완료라고 쓰지 않는다.
   현재 판단을 생략했다면 최종 AI 판단 시각과 이번 위험 점검 시각을 구분한다.
7. trade.py --account로 실제 체결·잔고를 다시 조회해 대시보드를 갱신한다. 주문을 재전송하지 않는다.
   board.py가 이 폴더에서 실행 중이면 재사용한다. 없으면 숨겨진 백그라운드로 실행한다.
   Windows Start-Process에는 -WindowStyle Hidden, 작업 폴더와 스크립트 절대경로를 지정한다.
   요약 한 줄, 판단 요청/생략/실패 이유와 미체결/손절 중 중요한 것 한 줄,
   http://127.0.0.1:8778 주소 한 줄로 보고한다. JSON·명령줄·개인 계좌 내역은 붙여넣지 않는다.

일일 기업발굴과 장중 회차만 활성 예약으로 둔다. 수집·판단·매매를 별도 동시 예약으로 중복 실행하지 않는다.
손절은 매시간 점검이며 정확히 -4% 체결을 보장하지 않는다. 멈추려면 'NH 자동매매' 예약을 일시 중지한다.
