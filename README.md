# NH자동매매 flow — aitrading

조코딩 NH투자증권 Namuh PLUG 예제를 바탕으로 만들었습니다.
**AI가 기업을 발굴하고, 독립 세 AI가 같은 자료·퀀트 점수를 검토해 매수·매도·보유를 판단합니다.**
퀀트는 공통 숫자 근거와 후보 순위이며 세 AI 판단을 대체하지 않습니다.

[한 장 설계](MULTIFLOW_PLAN.md) · [브라우저로 전체 구조 보기](http://127.0.0.1:8778/flow)

## 전체 흐름

매일 기업 발굴 → 장중 매시간 손절 점검 → 자료·퀀트 계산 → 필요 시 독립 세 판단 → 집계 → 주문 → 실제 체결 확인.

- 평일 07:30 ‘NH 기업발굴’: 테마 3개·관찰 기업 15~25개의 변화와 사업·재무 근거를 조사합니다.
  심층 보완은 하루 최대 3개, 전체 목록 검토는 7일마다입니다. 목록 전체를 매일 갈아엎지 않습니다.
- 평일 09~15시 매 정각 ‘NH 자동매매’: 연결 담당이 수집·퀀트·A/B/C·실행의 별도 Work에 순서대로 작업을 전달합니다.
- 평일 16:00 ‘NH 평가개선’: 별도 평가 Work가 결과와 누락 근거를 살피고 주 1개 이내 개선 실험을 제안합니다. 운영 규칙은 자동 변경하지 않습니다.
- 별도 ‘NH 기업선정’ 예약은 중지 상태를 유지합니다. 세 AI 판단은 장중 회차 안에서 필요할 때 수행합니다.
- 이 기기와 Codex 앱이 켜져 있어야 합니다. 터미널을 열어 둘 필요는 없습니다.
- 멈추려면 ‘NH 자동매매’ 예약을 일시 중지하면 됩니다.

## 무엇을 언제 사나요?

**점수 = 기업의 최근 60거래일 수익률 − 같은 기간 KODEX 200 ETF 가격 수익률**

기업 +8%, ETF +3%라면 점수 +5%포인트입니다. 앞으로 5% 오른다는 뜻은 아닙니다.
KODEX 200(069500)은 KOSPI200 대용이며 지수 자체·국내 전체 시장·총수익 지수가 아닙니다.
비교를 위해 조회할 뿐 이 ETF를 계좌에서 사는 규칙은 아닙니다.

오늘 미완성 봉을 제외한 61개 종가로 계산하며 기업과 ETF의 거래일이 모두 같아야 합니다.
공식 사업·재무 근거를 최근 확인한 기업 중 점수 양수,
완료된 20거래일 평균 거래대금 100억 원 이상인 후보를 점수 높은 순서로 검토합니다.
점수 양수라고 바로 사지는 않습니다. **세 유효 독립 응답 중 두 개 이상 매수에 동의해야 합니다.**
기본 금액은 15만 원 이내이며 찬성자의 작은 금액·가격 상한과 여력·비용 예약·정수 주 수를 따릅니다.
조건이 없으면 현금으로 기다리며 5개를 억지로 채우지 않습니다.

현재가·예산·동일 기업 미체결을 다시 확인합니다. 수집 당시 현재가의 +1%를 넘으면 매수를 보류합니다.
같은 기업·같은 신호일에 한 번만 매수 시도하며 취소·손절 후 같은 신호로 재진입하지 않습니다.
뉴스 검색 성공의 빈 결과는 허용하지만 조회 실패를 성공으로 취급하지 않습니다.

## 언제 파나요?

- 평균 매입가 대비 **-4% 이하**면 매시간 손절을 우선 점검합니다.
- 세 AI 중 두 개 이상 매도에 동의하면 매도합니다. 중대한 근거 훼손은 21일 전에도 반영할 수 있습니다.
- **21일마다 재평가**하며 점수와 근거를 세 AI가 다시 검토합니다. 기간·점수만으로 강제 매도하지 않습니다.
- 보유 연장은 양수 점수·최신 공식 근거·두 판단자의 명시적 연장이 모두 필요합니다.
- 자료 부족은 재평가 대기입니다. 검증하지 않고 연장 시각만 바꾸지 않습니다.
- 순위 하락만으로 교체하지 않습니다. RSI·MACD 매도·52주 고점 제외·고정 익절은 쓰지 않습니다.

손절은 증권사에 항상 대기하는 스톱 주문이 아닙니다. 매시간 확인 후 지정가를 보냅니다.
급락·갭·미체결·거래정지·PC/앱 중단으로 **실제 손실은 -4%보다 커질 수 있습니다.**
일봉·뉴스 수집이 실패해도 현재가 조회가 가능하면 별도 손절 점검을 먼저 수행합니다.

## 바꾸지 않는 제한

| 항목 | 현재 값 |
|---|---|
| 운용 예산 | 100만 원 |
| 시장 | 국내만 |
| 최대 보유 | 5개 |
| 종목당 상한 | 20만 원, 기본 검토 15만 원 이내 |
| 현금 기준 | 25만 원 이상 |
| 종목 손절 | 평균 매입가 대비 -4% |
| 계좌 손실 중단 | 초기 운용자산 대비 10만 원 손실 시 신규 매수 중단 |
| 재평가 | 21일마다 |
| 환경 | 모의투자 |

AI는 이 값을 바꾸지 않습니다. 큰 모의 계좌 잔액과 100만 원 운용 예산을 분리합니다.
계좌 손실 중단은 전량 청산과 다르며 자동 재개하지 않습니다.
기업 5개도 같은 수요에 묶이면 함께 하락할 수 있어 기업 수만으로 분산이 보장되지는 않습니다.

## 과도하지 않게 보완한 부분

- 데이터: 날짜·미완성 봉·종가·거래일 일치·단위·자본 변동을 검사합니다.
  일봉 거래대금(원)에 현재가 조회의 백만원 환산을 잘못 적용하지 않습니다.
- 주문: 기존 중복 주문·체결 대조·미체결 예약을 유지합니다.
  확인된 당일 모의 미체결은 1시간 후 잔량 취소 요청, 확정 전 예산 유지·불명 응답 재전송 금지를 지킵니다.
- 기록: 모든 후보·탈락·보류·실패·점수·결정서와 실제 순자산·확인된 체결을 로컬에 남깁니다.
- 비교: 현금 유지와 동일 관측 구간의 ETF 75%/현금 25% 가격 기준으로 수익·낙폭을 비교합니다.
  비교 ETF는 비용·배당 제외 기준이며 실매매가 아닙니다.

**현재 수익 우위는 미입증입니다.** 기능 검사 통과는 수익성 검증이 아닙니다.
관측 횟수를 독립 거래 수로 세거나 점수를 성공 확률로 바꾸지 않습니다.
전체 시장 백테스트·정교한 가상 체결·세 AI 성과 대조 실험을 완료한 것은 아닙니다.

멀티 워크 연결 후 프로젝트 테스트 178개와 전략 검사를 통과했습니다.
실제 별도 Work와 새 독립 A/B/C 세션으로 동일 입력의 15개 기업을 검토·집계했습니다.
검증 회차는 모두 관찰 유지였으며 운영 결정서를 게시하거나 주문하지 않았습니다.
일반 회차라면 현재 보유·사업/재무 검증 완료 기업이 없어 판단을 생략합니다.
이는 연결 검증이며 수익성 검증은 아닙니다. 실제 장중 주문·체결·취소 연결은 별도로 확인해야 합니다.
