NH자동매매 flow

같은 자료를 보고, 따로 판단하고, 결과로 개선합니다.

연결 담당이 각 워크의 완료를 확인한 뒤 다음 단계로 넘깁니다. 세 판단자가 매번 따로 검색하지 않습니다.

기업 발굴 → 수집·검증 → 퀀트 봉인 → 독립 A / B / C → 코드 집계 → 매매 실행 → 평가·개선
손절·계좌 위험 점검은 자료 수집과 AI 판단보다 먼저 실행합니다.
① 기업 발굴평일 07:30

테마와 밸류체인에서 관련 회사를 찾고 공식 사업·재무 근거를 확인합니다. 관찰 기업 15~25개, 하루 최대 3개 심층 보완.

② 수집·검증장중 매시간

시세·뉴스·계좌·보유를 한 번 모아 원본 시각과 입력 번호를 고정합니다.

③ 퀀트 검증수집 완료 후

60거래일 상대 강도를 재계산하고 날짜·단위·유동성을 확인합니다. 세 AI에게 같은 계산을 줍니다.

④ 독립 판단 A새 판단이 필요할 때

공통 자료만 보고 사업 근거·수치·반대 근거를 검토해 매수·매도·보유를 제출합니다.

⑤ 독립 판단 BA와 병렬

동일한 자료와 체크리스트를 봅니다. A와 C의 답은 보지 않습니다.

⑥ 독립 판단 CA·B와 병렬

같은 조건으로 독립 판단합니다. 매회 이전 대화가 없는 새 판단 세션을 사용합니다.

⑦ 매매 실행위험 점검 먼저 / 집계 후 실행

세 응답이 유효하고 두 표 이상 일치할 때, 퀀트·예산·현재가·미체결 조건까지 검사합니다.

⑧ 평가·개선평일 16:00

원본·판단·실제 결과를 비교합니다. 주 1개 이내 개선 실험을 제안하고 검토 전 운영 규칙을 바꾸지 않습니다.

공통 자료 약속

입력 번호·정책·시각이 다르거나 자료·응답이 빠지면 주문을 보류합니다. 셋이 갈리면 보유합니다. 실패를 보유 의견으로 채우지 않습니다.
