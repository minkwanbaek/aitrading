# 이전 업비트 프로젝트 보관

NH 자동매매로 개발 기준을 전환하면서 기존 파일을 내용 변경 없이 옮겼습니다.

- `autotrade.py`: 업비트 비트코인 자동매매
- `streamlit_app.py`: 거래 기록 조회 화면
- `strategy.txt`: 기존 투자 전략
- `requirements.txt`: 기존 의존성

보관 기준: 기존 main 커밋 `f9b50d8c893a4dd151beec97dbd9eba649165306`.
현재 개발 대상은 저장소 루트의 NH PLUG 코드입니다.

이전 코드는 실행 폴더에 상대적인 전략·DB·로그 경로와 dotenv 자동 검색을 사용합니다.
나중에 다시 실행하려면 별도의 작업 폴더·가상환경·업비트 설정을 준비해야 합니다.
현재 NH용 `.env`와 가상환경은 이 코드의 실행 환경이 아닙니다.
